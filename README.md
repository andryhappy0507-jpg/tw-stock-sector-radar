# 台股族群資金雷達

自動抓取 TWSE / TPEx 公開市場資料，建立台股股票母表、價量資料與每週族群資金雷達。

## V1 目標

- 全台股上市＋上櫃普通股
- 自動歸類產業／族群
- 每週判斷族群同步性
- 個股週漲幅 >= 5% 視為明顯轉強
- 週均量 >= 前 20 交易日日均量 1.5 倍視為明顯量增
- 族群至少 3 檔同步轉強、上漲家數比例 >= 60%
- 最終輸出 A / B / C 級族群觀察清單

## 價格訊號防呆

- `weekly_return_raw_pct` 保留未還原收盤價計算結果，供資料稽核。
- 五個交易日價格比超出 0.55–1.65 時，標記 `corporate_action_suspect`，避免除權、分割或價格斷點誤觸 A / B / C 訊號。
- 被排除的資料保留在 `weekly_signal.csv`，但 `weekly_return_pct` 設為空值，Theme 平均與上漲比只使用合格資料。
- 這是保守隔離機制，不等同完整還原價；後續仍可接入官方公司行動資料做精確調整。

> 目前為 V1 建置階段。
